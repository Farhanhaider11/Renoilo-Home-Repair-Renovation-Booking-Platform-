# Renoilo – Home Repair & Renovation Booking Platform

A modern full-stack home repair and renovation booking platform built with **Next.js** and **Odoo 19**.

The project is designed to provide a seamless experience for customers to browse services, submit booking requests, and manage their bookings through a clean and responsive interface.

---

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

### Backend
- Odoo 19
- Python
- PostgreSQL
- REST API

---

## Features

- Modern responsive UI
- Authentication pages
- Service listing
- Booking workflow
- Customer profile
- Booking history
- Odoo backend architecture
- REST API ready
